# Vector Search & Qdrant Collections Primitive

> **Last verified: 17/08/2026**
> **Brand: MODLIQER**
> **Status: Beta**

Manages vector collections, chunk embeddings, and semantic similarity search backed by Qdrant vector database.

---

## Capabilities & Endpoints
- **Create Collection**: `POST /api/v1/projects/:projectId/vector/collections`
- **List Collections**: `GET /api/v1/projects/:projectId/vector/collections`
- **Query Vector DB**: `POST /api/v1/projects/:projectId/vector/query`
- **DocuMind RAG Status**: `GET /api/v1/admin/ai/rag-status`
