# MODLIQER AI Labs Overview & Architecture

> **Last verified:** 17/08/2026


> **Status:** Beta / Experimental Showcase  
> **Feature Flag:** `AI_LABS_ENABLED=true`  

MODLIQER AI Labs provides experimental AI workflows separated from core manufacturing analytics and AutoML:

1. **DocuMind RAG:** PDF document intelligence with real page citations.
2. **Agent Task Pilot:** Bounded autonomous agent with LangGraph state machine and human approval gates.
3. **Voice AI Coach:** Real-time interruptible voice practice sessions with text fallback.
4. **Browser AutoQA:** Plain English web automation with Playwright execution and domain allowlisting.
5. **SpendLens:** Full AI receipt OCR extraction, field validation, and spend conversation.
