# Agent Run Manager Primitive

> **Last verified: 17/08/2026**
> **Brand: MODLIQER**
> **Status: Beta**

Provides audit trails, tool execution logs, step retries, and human approval status tracking for Agent Task Pilot executions.

---

## Capabilities & Endpoints
- **List Agent Runs History**: `GET /api/v1/projects/:projectId/agents/runs`
- **Get Agent Run Details**: `GET /api/v1/projects/:projectId/agents/runs/:runId`
- **Admin Agent Runs Audit**: `GET /api/v1/admin/ai-stack/agent-runs`
