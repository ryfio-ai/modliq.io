# Modliq Admin Console Documentation

## Features
- **User Account Directory**: Paginated, filterable table displaying User Name, Email, Role, Account Status, and **User Public ID** (`MODLIQ-USER-YYYYMMDD-1000`).
- **Global Search**: Filter users and entities by `publicId`, name, or email.
- **Admin Public ID Lookup**: Query any Public ID directly via `GET /api/v1/admin/lookup?publicId=...` for rapid customer support & telemetry investigation.
