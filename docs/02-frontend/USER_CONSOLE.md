# Modliq User Console Documentation

## UI Features
- **User Profile Setup Modal**: Onboarding popup requesting Full Name, Mobile Number, Organization, City, and Industry Sector.
- **User Profile View & Edit**: Live profile editor located at `/[userId]/modliq-console/profile`, featuring prominent **User Public ID** display (`MODLIQ-USER-YYYYMMDD-1000`).
- **Project Switcher & Header**: Project dropdown displays project name and **Project Public ID** (`MODLIQ-PROJECT-YYYYMMDD-1000`).
- **Quality Passport**: Certificate displays official **Passport Public ID** (`MODLIQ-PASSPORT-YYYYMMDD-1000`).
